# Recommendation Validation

**Version:** 1.0

---

# Purpose

The Recommendation Validation Engine validates every Recommendation Object before it is published.

Its responsibility is to ensure that recommendations are technically correct, business relevant, and ethically acceptable.

The Recommendation Validation Engine never generates recommendations.

It only validates recommendations generated by previous stages.

---

# Objectives

The Recommendation Validation Engine must

- Validate Recommendation Objects.
- Validate supporting Evidence.
- Validate business relevance.
- Validate score impact estimates.
- Validate truthfulness.
- Produce validated Recommendation Objects.

---

# Validation Philosophy

The Recommendation Validation Engine answers one question.

> "Can this recommendation safely and correctly be published?"

Every recommendation must satisfy all validation stages before publication.

---

# Validation Categories

## Technical Validation

Validate

- Recommendation ID
- Recommendation Category
- Priority
- Gap Reference
- Evidence Reference
- Metadata

---

## Business Validation

Validate

- Recommendation addresses a real Gap.
- Recommendation supports Job Description requirements.
- Recommendation provides measurable value.
- Recommendation is actionable.

---

## Ethical Validation

Validate

- Recommendation never suggests false skills.
- Recommendation never suggests fake experience.
- Recommendation never suggests fabricated certifications.
- Recommendation never suggests misleading projects.
- Recommendation promotes truthful Resume improvement.

---

## Reference Validation

Every Recommendation must reference

- Gap Object
- Evidence Object
- Job Description Requirement
- Resume Section

Broken references invalidate the recommendation.

---

## Impact Validation

Validate

- Estimated Score Gain
- Predicted Score Range
- Confidence Level

The estimates must exist and be internally consistent.

---

# Validation Status

Each Recommendation receives one status.

## Valid

All validation rules passed.

---

## Warning

Minor issue detected.

Recommendation may still be published.

---

## Invalid

Critical validation failure.

Recommendation must not be published.

---

# Validation Rules

## Rule 1

Every Recommendation must reference an existing Gap Object.

---

## Rule 2

Every Recommendation must reference supporting Evidence.

---

## Rule 3

Recommendations must never recommend false information.

---

## Rule 4

Recommendations must never duplicate another Recommendation.

---

## Rule 5

Estimated score improvements must be valid.

---

## Rule 6

Every Recommendation must be independently executable.

---

## Rule 7

Validation must always be deterministic.

---
