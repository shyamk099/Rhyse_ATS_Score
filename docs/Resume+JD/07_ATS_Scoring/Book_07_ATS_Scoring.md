# ATS Resume Intelligence Engine

# Book 07 — ATS Scoring Engine

**Version:** 1.0

---

# Purpose

The ATS Scoring Engine is responsible for calculating the final ATS Score for a Resume against a Job Description.

This is the only component within the ATS Resume Intelligence Engine that is permitted to calculate scores.

The ATS Scoring Engine consumes validated Evidence JSON and produces the Final ATS Score.

It never performs parsing, matching, evidence generation, or resume optimization.

---

# Objectives

The ATS Scoring Engine is responsible for

- Calculating ATS Compatibility Score.
- Calculating Resume Quality Score.
- Calculating Resume–JD Match Score.
- Calculating Semantic Validation Score.
- Applying Integrity Penalty.
- Producing Raw ATS Score.
- Calibrating the Raw Score.
- Producing Final ATS Score.

# Scoring Philosophy

The ATS Score represents the overall compatibility of a Resume for a specific Job Description.

The score is deterministic.

The score is explainable.

The score is reproducible.

Every score must be supported by validated evidence.

# Raw ATS Formula

The Raw ATS Score is calculated as

```
Raw ATS Score

=

ATS Compatibility Score

+

Resume Quality Score

+

Resume–JD Match Score

+

Semantic Validation Score

-

Integrity Penalty
```

The detailed weighting is defined in

- Weighted Scoring Engine

---

# Calibration

The Raw ATS Score is calibrated before publication.

Calibration is responsible for

- Score normalization
- Version consistency
- Score stability
- Cross-version comparability

Calibration never changes evidence.

Calibration only transforms the Raw Score into the Final ATS Score.

---

# Design Principles

## Deterministic

Identical Evidence JSON must always produce the same ATS Score.

---

## Explainable

Every score must be traceable to supporting evidence.

---

## Evidence Driven

The ATS Scoring Engine never performs Resume ↔ JD matching.

Only validated Evidence JSON is consumed.

---

## Immutable

Evidence JSON is never modified.

The ATS Scoring Engine only produces Score JSON.

---

## Version Controlled

Every score records

- Algorithm Version
- Weight Version
- Calibration Version
- Ontology Version
- Alias Dictionary Version
- Embedding Model Version

This guarantees reproducibility.

# Non-Responsibilities

- Generates evidence.
- Produces recommendations.

---

# Scoring Components

The Final ATS Score is composed of

## ATS Compatibility Score

Measures ATS readability and parsing compatibility.

---

## Resume Quality Score

Measures Resume quality using the shared Resume Quality Engine.

The same engine is used in both

- Resume Only Mode
- Resume + JD Mode

---

## Resume–JD Match Score

Measures how well the Resume satisfies the Job Description.

---

## Semantic Validation Score

Measures the quality of semantic evidence already generated by the Hybrid Knowledge Layer.

This component never performs new semantic matching.

---

## Integrity Penalty

Penalizes Resume manipulation.

Examples

- Keyword stuffing
- Hidden keywords
- Duplicate keyword abuse
- Artificial skill inflation

Integrity Penalty is bounded.

It cannot reduce the score below the configured minimum.

---

# Confidence

Confidence is not part of ATS Scoring.

Confidence is reported separately through the confidence pipeline.

Confidence never increases or decreases the ATS Score.
